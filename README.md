## Approved project identity

ETHEREALISM is a cinematic photography and film portfolio. Its approved design direction is one blue world, silver/pearl typography and a restrained orange counterlight; the original photographs and film stills remain the subjects.

The current project includes:
- Editorial hero and portrait/Viewfinder.
- 36-image photography sphere and 81-photo archive.
- Three film ribbons and 122 film stills.
- Featured project, filmography/photography archives, About and Contact.
- Optical Aperture background, static fine grain, frame-edge interaction lighting and one global audio engine.

The current project README and HANDOFF document the exact source, approved state, build identity, invariants and open decisions.
