These are proposed **display titles** for Framer headings, CMS entries, captions, and gallery navigation. They do not rename the underlying files in this commit. The source filenames remain intact so image references are not broken.

Because the GitHub file connector exposes the repository's text and file inventory but cannot render these binary photographs in this review, the individual names below are thematic editorial titles, not claims about visible image content. Confirm final pairings against the photographs before publishing literal captions or alt text.

## Naming and migration rules

- Use the proposed display titles in Framer first; retain original filenames as source identifiers.
- Keep the cover image field distinct from the gallery sequence.
- Use stable sequence values such as `01`, `02`, `03` in the CMS.
- Do not use poetic display titles as literal alt text.
- Do not physically rename or move assets until all Framer references have been checked.
