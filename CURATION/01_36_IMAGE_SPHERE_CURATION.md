### Sphere metadata fields

Each of the 36 records must carry:
- `photo_id` — stable unique ID shown above.
- `source_path` and `source_url` — canonical original file.
- `display_title` — title shown in the interface.
- `caption` — short text shown beneath the title in the selected state.
- `album_id` — album opened by this photograph.
- `collection_id` — broader collection identity.
- `category` — photographic discipline.
- `year` — currently unknown; leave null / omit until verified.
- `sphere_slot` — slot 01–36.
- `featured_in_sphere` — true.

Do not invent production years. If the current UI requires a year field, hide the field when its value is null rather than displaying a fabricated date.

## 5. Sphere presentation behaviour

The existing sphere is already an established interaction. Keep its current geometry and visual density.

**Preserve**
- 36 simultaneously displayed photographic frames.
- The central, overlapping composition.
- Cursor-driven rotation.
- Drag-to-steer behaviour.
- Existing 3D physics, spacing, scale, and established animation.
- The current dark environment and concise interaction instructions: **Move cursor to spin · Drag to steer · Click to open.**

**Refine only the content and navigation**
- Replace the current placeholder references with the 36 canonical image records.
- Each sphere frame references one photograph ID and one album ID.
- A sphere photograph is an entry into its parent album, not a standalone project page.
- Do not display permanent captions over all sphere frames.
- On hover or keyboard focus, reveal a restrained title and album label.
- On selection, show the selected photograph's title, category, optional verified year, short caption, and an **Explore album** action.
- Keep the existing previous/next and close affordances.

### Contextual navigation

There are two distinct navigation contexts:

1. **Sphere context:** previous/next moves through the 36 sphere entries. The counter may read `01 / 36`, etc.
2. **Album context:** after entering an album, previous/next moves only through that album's photographs. It must never jump to an unrelated album.

When the visitor closes an album or fullscreen image, restore the sphere exactly as it was:
- same 36 photographs;
- same rotation and orientation;
- same position and composition;
- same interaction state;
- no random redistribution or reconstructed sphere.

## 7. Asset integrity and final approval

- Preserve every source filename and original directory.
- Do not overwrite original photographs with edited or regenerated versions.
- Do not crop, stretch, recolour, desaturate, or retouch the source images for sphere use.
- Preserve each photograph's original aspect ratio.
- Do not duplicate a photograph record merely to make it appear in several places.
- If an image appears in the sphere, its sphere record points to the same canonical photograph record used by its album.
- Keep the complete album images accessible even if they are absent from the sphere.
- Write factual alt text only after inspecting the corresponding image. Display titles and poetic captions are not substitutes for alt text.
- The full 81-image title map and structured manifest are companion files in this curation folder.

**Visual sign-off note:** the current GitHub connector reliably exposed the nine Youthful Exuberance image sequence for visual review, but not all large JPEG originals. The 36-image selection is therefore the proposed editorial set reconciled to the current source inventory and previous selection. Before final production replacement, generate a contact sheet for the remaining large originals and confirm the composition of each selected preview.
